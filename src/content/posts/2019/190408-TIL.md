## Today I Learned

-   #### 오늘 한 일
    

-   ⭐️ `<dl>` tag에 대해서 배웠다.
    
    -   `<dl>` : Defines a definition list.
        
    -   `<dt>` : Defines a term/name in a description list.
        
    -   `<dd>` : Is used to describe a term/name in a description list.
        
        Ø 원래 `<dt>`와`<dd>` 를 `<div>`로 묶으면 안 됐었는데 허용됨
        
        : 다만 맞는 `<dt>`를 설명하는 모든 `<dd>` 함께 묶어야 함.
